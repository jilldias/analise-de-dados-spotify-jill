# Análise do Histórico de Podcasts no Spotify

Este repositório reúne estudos e experimentos realizados a partir dos dados pessoais exportados pelo Spotify.

O objetivo foi explorar técnicas de análise de dados utilizando Python, aplicando conceitos de manipulação de arquivos JSON, tratamento de dados com Pandas e visualização de informações.

Durante a análise, foram investigados aspectos como:

* Podcasts mais ouvidos;
* Episódios reproduzidos;
* Tempo total de reprodução;
* Distribuição dos temas de interesse;
* Identificação de padrões de consumo de conteúdo.

Além do aprendizado sobre análise de dados, o projeto serviu como prática de programação em Python e exploração de dados reais gerados pelo próprio usuário.

As análises foram desenvolvidas em ambiente Google Colab para fins de estudo, experimentação e aprimoramento de habilidades relacionadas à ciência de dados.
